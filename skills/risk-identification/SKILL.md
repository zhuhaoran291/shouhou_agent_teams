# 风险识别

## 用途

调查方案 Agent 完成事实调查后，用本技能检查历史退款记录和售后频次，识别异常信号，为风险分级提供输入。

## 输入

- 事实调查结果（证据链）。
- 订单历史退款记录、消费者售后频次。

## 步骤

1. 查询该订单的历史退款记录和累计退款金额。
2. 检查消费者近期售后频次是否异常偏高。
3. 检查图片或证据是否与历史案件重复。
4. 比对金额阈值和异常规则，输出风险信号列表。

## 输出契约

```json
{
  "case_id": "CS-1001",
  "risk_signals": [
    {"type": "", "detail": "", "evidence_ref": ""}
  ]
}
```

## 护栏

- 只报告风险信号，不据此直接拒绝用户。
- 风险判断必须基于数据，不主观猜测。
