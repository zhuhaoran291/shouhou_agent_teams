# 案件整理

## 用途

受理 Agent 完成诉求识别后，用本技能生成标准化的售后案件：绑定订单和商品、整理证据引用、列出缺失信息，供调查方案 Agent 继续处理。

## 输入

- 投诉文本和诉求识别结果。
- 消费者资料和订单搜索结果。
- 消费者提交的证据引用列表。

## 步骤

1. 按消费者信息搜索订单，定位与投诉匹配的订单和商品。
2. 绑定订单号、商品清单和证据引用到案件。
3. 对照案件必填字段检查完整性，列出缺失信息（如缺订单号、缺证据、缺具体商品）。
4. 创建案件并输出标准案件 JSON。

## 输出契约

```json
{
  "case_id": "CS-1001",
  "intent": "退款/补发/换货/维修/投诉",
  "order_id": "订单号",
  "products": [],
  "issue": "问题描述",
  "evidence_refs": [],
  "missing_info": []
}
```

## 护栏

- 缺失信息必须显式列出，不得臆测或编造。
- 只能整理案件，不能判断责任、不能承诺退款、不能修改订单、库存或支付状态。
