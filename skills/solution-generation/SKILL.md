# 方案生成

## 用途

调查方案 Agent 完成事实调查和风险识别后，用本技能生成候选售后方案：退款、退货退款、补发、换货、维修、补偿或拒绝并解释。

## 输入

- 事实调查结果（证据链）。
- 售后政策、处理规则和金额阈值。
- 可用库存和补发可行性。

## 步骤

1. 基于事实和政策判断用户可获得哪些售后权益。
2. 生成推荐方案和备选方案，计算可退金额或补发可行性。
3. 比较候选方案的用户体验、成本、时效和风险。
4. 输出推荐方案并附政策依据。

## 输出契约

```json
{
  "case_id": "CS-1001",
  "recommended_action": {"type": "退款/补发/换货/维修/补偿", "amount": 0, "detail": {}},
  "alternatives": [],
  "policy_basis": ""
}
```

## 护栏

- 方案必须可执行、有依据。
- 不绕过政策给特殊补偿；不直接执行退款或创建补发单。
