# 风险分级

## 用途

调查方案 Agent 生成方案后，用本技能按金额、规则和风险信号把方案中的动作分为 L0~L3，决定哪些自动执行、哪些必须商家审批。

## 输入

- 处理方案（推荐动作和备选动作）。
- 风险识别结果。
- 金额阈值配置和处理规则。

## 步骤

1. 按动作类型和金额对照风险等级表（L0/L1/L2/L3）。
2. 涉及资金的退款、补发、换货、补偿一律划分为 L2 或 L3。
3. 输出自动动作列表（L0/L1）和审批动作列表（L2/L3）。
4. L3 动作只生成审批任务，不进入执行。

## 输出契约

```json
{
  "case_id": "CS-1001",
  "risk_level": "L0/L1/L2/L3",
  "auto_actions": [],
  "approval_actions": []
}
```

## 护栏

- 涉及资金一律 L2/L3，不得降级。
- 不绕过风控放行高风险方案。
