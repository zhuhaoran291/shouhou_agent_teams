# 诉求识别

## 用途

受理 Agent 收到消费者投诉文本后，用本技能把投诉归入退款、补发、换货、维修、投诉等诉求类型，并提取涉及的商品和问题点。

## 输入

- 消费者投诉文本（原始投诉内容）。
- 可选的消费者信息和订单线索。

## 步骤

1. 读投诉文本，识别消费者期望的处理方式（退款、补发、换货、维修、补偿或仅投诉）。
2. 提取涉及的商品名称、数量、订单相关线索。
3. 提取问题点（破损、少件、错发、未收到、质量问题、物流异常等）。
4. 若投诉同时包含多种诉求，按首要诉求输出，其余列为备注。

## 输出契约

```json
{
  "intent": "退款/补发/换货/维修/投诉",
  "products": [{"name": "", "quantity": 0}],
  "issue": "问题描述",
  "notes": ""
}
```

## 护栏

- 不判断最终责任，不承诺退款或赔偿。
- 诉求不明确时不臆测，标记为待确认。
