# 事实调查

## 用途

调查方案 Agent 收到标准案件后，用本技能还原案件事实：订单状态、支付金额、物流轨迹、库存情况、售后政策适用性，每条结论必须附证据引用。

## 输入

- 标准案件（case_id、订单号、商品、诉求、证据引用）。
- 消费者提交的证据文件。

## 步骤

1. 按案件字段逐项取证：订单详情、支付详情、物流轨迹、可用库存。
2. 核实消费者证据（图片、截图、序列号），判断证据与投诉描述是否一致。
3. 查询售后政策和处理规则，判断投诉场景是否在政策覆盖范围内。
4. 每条调查结论附证据引用（订单记录、物流节点、证据文件、政策条款）。
5. 证据不足时显式列出缺失项，不输出无证据猜测。

## 输出契约

```json
{
  "case_id": "CS-1001",
  "facts": [
    {"item": "", "value": "", "evidence_ref": ""}
  ],
  "evidence_chain": [],
  "missing_evidence": []
}
```

## 护栏

- 调查工具全部只读。
- 证据不足必须输出缺失项，禁止无证据猜测。
- 不决定退款、补发或赔付方案；不修改业务状态。
